# UniFi Access MQTT

Home Assistant add-on wrapper for upstream release `v0.6.1` of the
[`mqtt-home/unifi-access-mqtt`](https://github.com/mqtt-home/unifi-access-mqtt)
gateway. It bridges UniFi Access events to MQTT and can wake a UA Intercom
Viewer with the controller's private mTLS MQTT broker.

See [DOCS.md](DOCS.md) for setup and certificate handling.
